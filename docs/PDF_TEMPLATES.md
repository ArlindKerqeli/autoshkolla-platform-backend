## Overview

This document specifies the exact layout, content, and styling for all PDF documents generated by Autoshkolla Platform. The system generates 7 distinct document types for driving school management in Kosovo.

### Key Requirements

- **PDF Engine**: WeasyPrint with Jinja2 HTML templates
- **Paper Size**: A4 (210mm × 297mm) for all documents except Libreza (landscape A4)
- **Language**: Albanian (Kosovo dialect) for all user-facing text
- **Date Format**: `dd.MM.yyyy` throughout all documents
- **Currency**: Euro (€) symbol
- **Fidelity**: 100% pixel-perfect match to original system layouts
- **Character Support**: Must support Albanian special characters (ë, ç, etc.)

### Directory Structure

```
backend/app/pdf/
├── templates/                    # Jinja2 HTML templates
│   ├── fatura.html              # Invoice
│   ├── fleteparaqitja.html      # Registration form
│   ├── libreza.html             # Candidate logbook
│   ├── kontrata.html            # Contract
│   ├── testi.html               # Test results
│   ├── vertetimi.html           # Verification certificate
│   └── candidate_list.html      # Candidate export list
├── styles/
│   ├── pdf_base.css             # Shared PDF styling
│   └── pdf_fonts.css            # Font definitions for Albanian characters
├── assets/
│   ├── coat_of_arms.png         # Kosovo coat of arms (200×200px)
│   ├── school_logo.png          # Placeholder for school logo
│   └── traffic_signs/           # Traffic sign images for test documents
│       ├── sign_1.png           # B1
│       ├── sign_2.png           # B2
│       └── ...                  # Additional traffic signs (25 total)
└── generator.py                 # WeasyPrint generator service (business logic)
```

### Margin & Layout Standards

- **Default Margins**: 15mm top, 15mm right, 15mm bottom, 15mm left
- **Page Header Height**: 30mm (for government forms)
- **Page Footer Height**: 15mm
- **Table Padding**: 3-4mm between cells
- **Font Family**: `Arial, Helvetica, sans-serif` (system fonts with fallback)
- **Base Font Size**: 11pt (adjust per section)
- **Line Height**: 1.4 for readability

### Template Rendering Chain

1. **Data Preparation**: Query database for candidate, tenant, category data
2. **Template Rendering**: Jinja2 renders HTML with variables
3. **CSS Injection**: Embed `pdf_base.css` + document-specific styles
4. **PDF Generation**: WeasyPrint processes HTML+CSS → PDF bytes

### Jinja2 Filters

Define a custom date filter:

```python
# In app/__init__.py or utils/serialization.py
@app.template_filter('format_date')
def format_date(date_obj):
    """Format date as dd.MM.yyyy"""
    if isinstance(date_obj, str):
        return date_obj
    return date_obj.strftime('%d.%m.%Y')
```

## Special Considerations

### 1. Albanian Language & Localization

All text in PDF templates must be in Albanian (Kosovo dialect):
- Dates: `dd.MM.yyyy` (e.g., "09.03.2026")
- Days of week: "e hënë", "e martë", etc.
- Months: "janar", "shkurt", "mars", etc.
- Currency: "€" or "Euro"
- Numbers: Use Albanian for contract text (e.g., "njëzet" for 20)

Use Albanian-specific fonts that support characters: ë, ç, è, é, ù, ñ

### 2. Image Assets

**Kosovo Coat of Arms**:
- Source: Official government website
- Size: 200×200px PNG with transparent background
- Location: `backend/app/pdf/assets/coat_of_arms.png`

**School Logo**:
- Placeholder: Blue shield with car icon
- Dynamic: Load from `tenant.logo_url` if available
- Fallback: Use placeholder if not available
- Size: 40×40mm for invoice header

**Traffic Signs**:
- 25 traffic sign images for test document
- Size: ~100×100px each
- Format: PNG with transparent background
- Location: `backend/app/pdf/assets/traffic_signs/`

### 3. Pagination & Page Breaks

- Use CSS `page-break-before: always;` and `page-break-after: always;`
- Use `page-break-inside: avoid;` for tables and question blocks
- Test multi-page rendering carefully (especially Testi, Libreza, Candidate List)

### 4. Character Boxes (Personal Numbers)

Personal number displays as 10 individual boxes:
```html
{% for digit in candidate.personal_number %}
  <span class="char-box">{{digit}}</span>
{% endfor %}
```

Each box must be exactly 6mm × 6mm with 1px black border.

### 5. Filtering & Dynamic Content

For Candidate List export, support filters:
- By category (single or multiple)
- By date range (registration_date)
- By status (active, archived, verified)
- By instructor

### 6. Soft Deletes

When generating PDFs:
- Filter out candidates with `deleted_at IS NOT NULL`
- Include archived candidates unless filtered out
- Distinguish archived candidates in candidate list (different styling)

### 7. Multi-Tenancy

All PDF endpoints must:
- Verify `tenant_id` from JWT token
- Filter candidate data by `tenant_id`
- Use tenant-specific data (address, phone, email, bank info)
- Never expose another tenant's data

## Troubleshooting Guide

### Common WeasyPrint Issues

**Problem**: Albanian characters (ë, ç) not rendering
- **Solution**: Add font-family with DejaVu Sans or Liberation Sans
- Ensure font supports Unicode

**Problem**: Images not loading in PDF
- **Solution**: Use absolute paths or embed base64
- Verify image file exists at path
- Check file permissions

**Problem**: Tables breaking across pages incorrectly
- **Solution**: Add `page-break-inside: avoid;` to table rows
- Reduce row height if necessary
- Test with various content lengths

**Problem**: PDF generation timeout (large documents)
- **Solution**: Optimize CSS (avoid complex selectors)
- Reduce image file sizes
- Consider pagination for large exports
- Implement async PDF generation with Celery

**Problem**: Signature/stamp areas blank
- **Solution**: These are intentional empty spaces for manual signing
- Verify box dimensions are sufficient
- Use border and dashed lines for guidance
